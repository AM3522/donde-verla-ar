# Glosario
- **Título**: serie o película con ficha propia.
- **Plataforma**: servicio de streaming con planes (Netflix, Prime Video, HBO Max, Disney+, MUBI).
- **Plan**: opción de suscripción de una plataforma, con precio mensual, con o sin anuncios.
- **Precio base**: precio mensual publicado, sin impuestos.
- **Precio final**: precio base con IVA y percepción de Ganancias.
- **Vigente**: disponibilidad sin fecha "hasta", o con fecha de hoy o futura.
- **Cobertura**: cantidad de títulos de una lista que se pueden ver con una combinación de plataformas.
- **Combinación**: conjunto de plataformas que se suscriben a la vez.
