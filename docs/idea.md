# Idea: Dónde verla
Wiki de series y películas para Argentina. Cada ficha tiene: resumen breve, plataformas donde está hoy (solo Argentina), idiomas de audio y subtítulos, y precio de los planes.
Extra: indica la forma más barata de ver un título o una lista completa de títulos.
Usuarios: visitante (consulta) y editor (mantiene catálogo y precios en archivos JSON).
Fuera de alcance: reproducir contenido, cuentas de usuario, reseñas, otros países.
